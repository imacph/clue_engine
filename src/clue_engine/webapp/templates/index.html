Toolkit scores describe enabled techniques, not win probability.

How the toolkit score works

Possible-card suggestions count 20 points; probes, ranking, repeat reveals, and possible-room preference each count 15. Card-only suggestion priority counts 10. Only options applicable to the game type count, scaled to 100. All bots share deduction and legal movement.
